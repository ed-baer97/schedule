# CoAlly pending — 2026-08-13 (scrollbar)

CoAlly sync failed (timeout). Payload to retry:

- **task_description:** Fix frontend horizontal scrollbar appearing only at page bottom
- **project_name:** schedule
- **author:** Cursor
- **mark_task_done:** true
- **modules_affected:** frontend/src/styles/theme.css, frontend/src/pages/WorkloadPage.tsx

## details

Bug: the bottom (horizontal) scrollbar on the React frontend only appeared after scrolling to the end of a long page.

Root cause: .app-shell used min-height: 100vh (grows with content), .app-main had overflow-x: auto but unconstrained height. Combined with Bootstrap .table-responsive { overflow-x: auto }, the horizontal scrollbar was attached to a wrapper as tall as the full table/page. The browser paints that bar at the bottom of that tall box, so it is only visible after scrolling the document to the end.

Fix in frontend/src/styles/theme.css:
- html, body, #root: height 100%; overflow hidden (no document-level scroll)
- .app-shell: height 100%; overflow hidden (was min-height 100vh)
- .app-body: overflow hidden + existing min-height 0 so flex children can shrink
- .app-main: overflow auto + min-height 0 so it is the viewport-sized scrollport; both bars sit at the visible edges of the main column
- .app-main .table-responsive { overflow: visible } so wide tables contribute to .app-main scrollWidth instead of a nested inner bar
- print: restore height auto / overflow visible so reports still print fully
- mobile: .app-sidebar max-height 40vh (was none) because the page no longer grows with the nav

WorkloadPage keeps maxHeight 70vh with inline overflow auto so its sticky-top header still works inside a capped table wrapper.
