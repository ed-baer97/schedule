# Система составления школьного расписания

## Цель проекта

Создать веб-сервис для удобного составления и управления школьным расписанием с возможностью ручного и автоматического формирования.

---

## Основные сущности

| Сущность | Описание |
|----------|----------|
| **Учителя** | ФИО, контакты |
| **Кабинеты** | Номер, название, корпус, вместимость |
| **Классы** | Название (1А, 5Б), уровень (начальная/основная школа), смена |
| **Предметы** | Название, краткое название, цвет для отображения |
| **Назначения** | Связь: предмет ↔ учитель ↔ класс(ы), часы в неделю, подгруппа |
| **Смены** | Название, к какому уровню школы относится, количество уроков |

---

## Ключевые правила бизнес-логики

### Подгруппы
- Если **2 учителя** преподают **один предмет** в **одном классе** → предмет делится на подгруппы
- В одну ячейку расписания можно добавить несколько предметов **только если** они разбиты на группы
- Подгруппы могут проходить одновременно в разных кабинетах

### Структура расписания
- Расписание делится на: **Начальная школа** / **Основная школа**
- Внутри каждого уровня — деление на **смены**
- Классы привязаны к конкретной смене

### Настройки
- Количество учебных дней в неделе (5 или 6)
- Максимальное количество уроков в день
- Отдельные настройки для каждого уровня школы

## Ввод данных

### Импорт из Excel (первоначальная загрузка)

**teachers.xlsx** — список учителей:
| ФИО | Краткое имя | Email | Телефон |

**curriculum_elementary.xlsx / curriculum_secondary.xlsx** — учебный план:
- Строки = классы (1А, 1Б, 2А...)
- Столбцы = предметы (Русский, Математика...)
- Ячейки = часы в неделю (0 = не преподаётся)

### Редактирование в системе

Все сущности можно добавлять, редактировать и удалять через веб-интерфейс.

## Важные принципы

1. **Простота первична** — сначала рабочий MVP, потом улучшения
2. **Валидация везде** — не допускать некорректных данных
3. **Юзабилити** — интерфейс должен быть понятен завучу без инструкций
4. **Гибкость** — разные школы имеют разные требования
